## 🔍 What it Detects

This model is trained to recognize 4 critical elements on a manga page:
* 🖼️ **Panels:** Individual comic/manga panels.
* 💬 **Speech Bubbles:** Dialog and thought containers.
* 📝 **Text:** Raw text blocks inside or outside bubbles.
* 💥 **SFX:** Sound effects and stylized lettering.
